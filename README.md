# peace-shillong.github.io

Updated : April 15, 2026

This is my Personal Github Page.
Built with modern HTML5, CSS3, and JavaScript.

## Features

- **Modern HTML5**: Semantic HTML structure with proper accessibility
- **Responsive Design**: Mobile-first approach with CSS Grid and Flexbox
- **Clean CSS**: Modern CSS with custom properties (CSS variables)
- **Performance**: Optimized fonts, images, and no unnecessary JavaScript
- **Accessibility**: Proper alt texts, semantic markup, and keyboard navigation

## Technologies Used

- HTML5
- CSS3 (Grid, Flexbox, Custom Properties)
- Google Fonts (Raleway, Roboto, Satisfy)
- Google Analytics

## Development

The website has been modernized from the original Skeleton CSS framework to use modern web standards:

- Replaced jQuery with vanilla JavaScript (removed entirely as it wasn't being used)
- Updated to semantic HTML5 elements
- Implemented CSS Grid and Flexbox for responsive layouts
- Added CSS custom properties for theming
- Improved typography and spacing
- Enhanced accessibility and SEO
